## 问题

做 LLM 应用时，开源模型和闭源 API 各有什么优劣？如何选型？

## 核心答案

**闭源 API（GPT / Claude / Gemini 等）**：

- 优势：能力上限高、迭代快、开箱即用、配套生态（多模态/工具调用/长上下文）成熟；
- 劣势：按 token 持续付费且成本随量线性涨、数据出域（合规敏感场景受限）、不可深度定制、服务与版本受厂商控制。

**开源/开放权重模型（LLaMA、Qwen、DeepSeek 等）**：

- 优势：可私有化部署（数据不出域）、无按量 API 费用（换算力固定成本）、可微调定制、版本与依赖自主可控；
- 劣势：需自建推理与运维能力、顶尖能力通常略落后于最强闭源模型、效果调优需要专业投入。

**选型维度**：

1. 数据合规：强合规（金融/医疗/政务）优先私有化开源；
2. 能力要求：前沿能力（复杂推理、多模态）优先闭源 API；
3. 成本结构：高频海量调用，自部署可能更省；低频长尾，API 更划算；
4. 团队能力：有无推理运维与训练经验；
5. 常见落地形态：**分层混用**——复杂任务用闭源/大模型，简单任务用开源/小模型（配合网关路由）。

## 深度解析

- 闭源模型版本会下线或行为变化，应用层要做模型抽象与评估回归，避免被单一供应商锁定；
- 私有化部署的真实成本 = GPU 算力 + 推理优化 + 运维人力，不只是「下载权重免费」；
- 开源模型许可协议各有条款（商用限制、品牌使用），商用前要核对 license。
