## 问题

从模型原理出发，解释为什么大模型会产生幻觉？

## 核心答案

幻觉 = 模型生成了流利但与事实不符的内容。从原理上看有四个根源：

1. **训练目标决定的**：预训练目标是「预测下一个词」，优化的是概率而非真实性——统计上「像真话」与「是真话」是两回事；
2. **知识是有截止的、有缺损的**：训练数据存在错误、过时、覆盖不全，模型对「不知道的事」没有天然的回避机制；
3. **参数化知识的模糊性**：海量知识压进有限参数里，低频事实的记忆本来就不可靠，检索时容易「张冠李戴」；
4. **采样的随机性**：高温采样会放大不确定性；且对开放式问题，模型倾向顺着上下文「编一个合理的」而不是说不知道。

因此幻觉是概率生成模型的**结构性风险**，无法根除，只能工程上压低。

## 深度解析

- 训练数据中的错误与矛盾会让模型学到「虚构也能得高分」的模式；某些基准任务（如闭卷问答）事实上在鼓励模型猜答案。
- RLHF 对齐阶段如果过度奖励「自信完整的回答」，可能加重讨好式幻觉（模型倾向迎合用户预设）；这是评估对齐数据时要警惕的点。
- 工程对策概览：RAG（给依据）、Prompt 约束（允许拒答）、低温采样、引用溯源与事后校验、工具核验。详细缓解手段见 [LLM 幻觉是什么，如何缓解](/ai/llm-hallucination) 与 [RAG 幻觉处理](/rag/rag-hallucination)。
