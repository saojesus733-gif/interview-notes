## 问题

AI 领域变化这么快，你是怎么快速学习新技术的？举个例子。

## 核心答案

**方法论（四条，每条配一个证据）**：

1. **以输出倒逼输入**：学一个领域的标志是能讲出来/做出来——例：为系统复习 LLM 面试知识，从零搭了一个带随机抽题、掌握度追踪的知识库网站（VitePress + Vue），本身就是一次完整工程实践；
2. **先跑通全链路再深入细节**：用最小项目把"检索→生成→评估"整条链路走通，先有全局感，再定点深挖（比如专攻 Rerank 或评估）；
3. **读一手资料**：优先官方文档与原始论文，二手教程只做入门导航——避免被过时/错误的二手信息带偏；
4. **建立客观反馈**：学习效果用可量化的东西验证（题库刷题正确率、项目评估集指标），而不是"感觉学会了"。

**举例要求**：完整讲一个例子（比如学会 RAG：跑通 demo → 深挖切分/检索/评估 → 输出笔记与项目），有始有终。
