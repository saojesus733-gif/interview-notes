## 问题

"你好像没有在生产环境做过 AI 项目？"——被问到这个问题应该怎么回答？

## 核心答案

**答题结构：承认 → 等价证据 → 可迁移能力 → 成长速度**：

1. **坦然承认，不绕弯子**："生产环境的 LLM 项目我确实还在积累，这也是我投这个岗位的原因"——诚实本身就是加分项，遮掩会被追问穿；
2. **给出等价证据（三层）**：
   - **后端项目里的 AI 触点**：只要沾边就讲（业务系统里接过智能客服模块、给内部工具加过 LLM 能力）；
   - **完整的个人项目**：端到端做过的 RAG/Agent 项目，重点讲设计取舍与评估数据——规模小没关系，**闭环完整**才是证明点；
   - **学习产出**：这个知识库网站、笔记体系，证明学习速度与工程习惯；
3. **可迁移能力对齐**：稳定性保障、性能优化、数据处理、服务治理——AI 应用团队每天缺的就是这些；明确说"模型侧我需要学，工程侧我第一天就能顶上"；
4. **成长速度背书**：用时间线证明（多长时间内完成了知识库+项目+这些题的体系化）。

## 深度解析

- 面试官的底层动机是**风险控制**：怕招一个只会谈概念、上线就掉链子的人——所以破解点全部围绕"可验证的产出"，而不是态度表达；
- **绝对不要编造项目经历**：AI 面试的项目追问极深（你的评估集怎么建的？切分参数为什么这么设？），编的经历两三层就露馅，且属于一票否决；
- 反客为主的机会：讲清楚"我系统研究过 AI 项目上线后会遇到什么问题（幻觉/成本/评估）"——用预判能力弥补经验空缺。
