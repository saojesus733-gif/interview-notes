## 问题

技术面试开场的自我介绍，怎么准备？请给出适合"后端工程师转型 AI 应用方向"的版本结构。

## 核心答案

**结构：四段式，控制在 90 秒~2 分钟**：

1. **一句话身份**：姓名 + 年限 + 技术定位（"X 年服务端开发经验，主攻高并发业务系统，近一年聚焦 LLM 应用开发"）；
2. **后端亮点（2 句）**：挑 1~2 个有数字的成果（"把核心接口 P99 从 X 降到 Y""负责日均 X 万订单的子系统"）——证明工程底子；
3. **AI 方向投入（2~3 句）**：学了什么、做了什么（"系统学习 RAG/Agent 技术栈，独立完成了一个带评估体系的问答系统，包括检索优化、Prompt 管理、掌握度追踪"）——证明不是纸上谈兵；
4. **匹配点收尾（1 句）**："后端的稳定性与性能经验，恰好是 LLM 应用落地的稀缺能力"——呼应岗位。

**技巧**：埋钩子——故意留一个亮点不讲透（如"其中有个检索优化挺有意思"），引导面试官顺着你的主场提问。

## 深度解析

- 常见错误：背简历流水账（没有重点）、只讲后端（与岗位无关）、只讲 AI（丢掉差异化优势）；
- 每段都要有"可被追问的实料"，自我介绍里说的每个词都要能扛住两层追问；
- 按岗位微调：偏工程的 AI 岗多讲工程指标，偏算法的岗位补讲评估与数据。
