## 问题

你做了多年后端，为什么现在要转 AI Agent / 大模型应用方向？是不是在追热点？

## 核心答案

**回答结构：事实判断 → 亲身契机 → 已有行动 → 未来一致性**：

1. **事实判断**：LLM 应用的瓶颈正在从"模型能力"转向"工程落地"——检索质量、稳定性、成本、评估体系，这些恰恰是服务端工程师的主场；
2. **亲身契机（必须具体）**：讲一个真实接触点（如"在业务里接入过一个 LLM 能力，发现难点不在模型而在工程"），证明是实践后的判断，不是看新闻；
3. **已投入的行动**：系统学习的技术栈清单 + 可验证产出（项目/仓库/这个知识库网站本身）；
4. **一致性收尾**：这不是转行而是延伸——后端能力（高并发、稳定性、数据）+ AI 应用层 = 更完整的交付能力。

**关键姿态**：说"延伸和叠加"，不说"逃离后端"；不贬低原方向，不神化新方向。

## 深度解析

- 面试官的三个真实关切：你会不会干半年发现落差又回去？你技术底子撑不撑得住？你是想清楚了还是投机？
- 高危追问预案："如果 AI 应用遇冷怎么办"→ 答：这套能力（数据/评估/工程化）在任何技术周期都有价值，且我的后端底子没有丢；
