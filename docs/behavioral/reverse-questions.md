## 问题

面试尾声"你有什么想问我的吗"——这一环节应该问什么、避免问什么？

## 核心答案

**为什么重要**：反问是你少数的主动权——既是展示真实兴趣的机会，也是你评估团队的信息窗口。至少准备 3 个，用掉 1~2 个。

**好问题的方向**：

1. **团队的真实挑战**："团队目前在 LLM 落地中最大的痛点是效果、成本还是数据？"——显示你懂这个行业的问题结构；
2. **入职后的预期**："如果我有幸入职，前三个月你期望我做出什么？"——直接对齐交付预期；
3. **工程与评估文化**："团队的模型/Prompt 变更怎么验证质量？有评估体系吗？"——懂行的人才会问这个；
4. **成长路径**："团队里做得好的工程师通常具备什么特质？"

**避免问**：薪资福利细节（留给 HR 轮）、官网能查到的信息、加班与调休（首轮问这个信号不好）、"你觉得我表现怎么样"（强人所难）。

## 深度解析

- 面试官把反问当"筛选信号"：问挑战 = 有真实兴趣；问评估体系 = 有工程素养；什么都不问 = 兴趣不足或没准备；
- 反问也是你的**尽调**：从面试官回答的具体程度可以判断团队是真落地还是 PPT 阶段（答不出评估体系往往意味着应用还在早期）；
- 面试后复盘时记录反问得到的信息，用于多 offer 之间的比较决策。
