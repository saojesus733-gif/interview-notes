## 问题

给定一个只包含 `'('`、`')'`、`'{'`、`'}'`、`'['`、`']'` 的字符串 `s`，判断字符串是否有效。有效需满足：左括号必须用相同类型的右括号闭合，并以正确的顺序闭合；每个右括号都有一个对应的同类型左括号。

示例：

- 输入：`"()[]{}"`，输出 `true`
- 输入：`"(]"`，输出 `false`
- 输入：`"([)]"`，输出 `false`（交叉嵌套不合法）
- 输入：`"{[]}"`，输出 `true`

## 核心答案

- 核心思想：括号匹配满足「后进先出」——最新出现的未闭合左括号必须最先被闭合，与栈的行为完全一致。
- 关键步骤：遇到左括号，把「它期望的右括号」压栈；遇到右括号时，栈顶必须恰好等于该右括号，匹配则弹栈，否则无效。
- 奇偶剪枝：长度为奇数的字符串必然无法完全配对，直接返回 false，省去一次遍历。
- 三种失败情况：右括号到来时栈为空（右括号多了）、栈顶不匹配（顺序错误）、遍历结束栈非空（左括号多了）。
- 复杂度：时间 O(n)，空间 O(n)，最坏情况字符串全部是左括号。

## 深度解析

参考实现：左括号入栈时期望的右括号，省去三组配对 if 判断，逻辑更简洁。

```java
public boolean isValid(String s) {
    if (s.length() % 2 == 1) return false;   // 奇数长度必不合法，提前剪枝
    Deque<Character> stack = new ArrayDeque<>();
    for (char c : s.toCharArray()) {
        if (c == '(') {
            stack.push(')');                 // 压入期望的右括号
        } else if (c == '[') {
            stack.push(']');
        } else if (c == '{') {
            stack.push('}');
        } else if (stack.isEmpty() || stack.pop() != c) {
            return false;                    // 栈空（右括号多）或不匹配（顺序错）
        }
    }
    return stack.isEmpty();                  // 栈非空说明左括号有剩余
}
```

- 易错点：最后直接返回 true 而忘记检查栈空，`"((("` 会被误判为有效；右括号分支不判空直接 pop 会抛异常；Java 建议用 Deque 而非遗留的 Stack。
- 变体题：最长有效括号（LeetCode 32，栈存下标或 DP）、删除字符串中的最外层括号、生成括号（回溯）。
