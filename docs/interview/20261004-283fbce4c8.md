面试职位：搜广推引擎架构- base open - Data-抖音/直播/电商/剪映

个人项目：语义模糊搜索引擎

实习项目：企业内部行政HR助手

这个面试真是给我面乐了，没见过这么搞笑的。

【实习项目】

- 整体技术链路是什么样的？

- 系统、子系统和最小粒度模块如何划分？

- 项目效果的提升具体做了哪些工作？

- 如果 Agent 必须输出指定格式，例如 JSON，应该怎样设计，保证输出符合要求？

【个人项目】

我讲完个人项目的介绍以后，他问：

- 如果你的项目有100000000个人用，怎么办？

 我说，那你先说说你给我几张卡呢？如果我这个个人小项目有100000000个人用，我难道还需要面试你的岗位吗？要不你来我这里给我做优化吧，等咱俩干翻豆包了，到时候我分给你30%股份。

- 我感觉你这个项目没什么用啊

好好好，刚问完有10000000个人用怎么办，又说没什么人用，你搁这左右脑互搏呢？没什么用那我线上大几百万次使用量怎么来的？是我懂我的用户还是你懂啊？

- 了解HNSW算法吗？

【基础知识】

- 你是计算机专业的吗？

我又绷不住了，我寻思我个人介绍的第一句话就是我是EE专业的吧。

- 进程、协程和线程这三个概念，你大概说一下自己的理解。

- 线程之间共享地址空间，那么哪些内容是线程私有的？

- 假如 TCP 只有两次握手：一个旧连接请求在网络中滞留很久，客户端重新发起连接，正常通信并断开后，旧请求才到达服务端，这时可能发生什么不好的事情？

- 现在有大量用户及订单，要按用户当天的购买数量、金额等计算价值分，评分方法简单但可能变化；需要生成每天的 Top K 日榜并向用户展示。你会怎么设计？
