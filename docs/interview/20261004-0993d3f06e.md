#如何准备秋招#
面试职位：安全技术-风控算法方向-Agent开发
个人项目：模糊语义搜索引擎
实习项目：企业内部行政HR助手

【个人项目】
1. 这个映射的真正难点是什么？为什么直接翻译或问大模型不够？
2. 你如何把描述映射到目标标签？
3. 技术细节选型追问
4. 如果用户描述一个具体物品，返回结果却包含大量泛化类别和属性词，这些词虽然语义相关却没有实际帮助，怎么处理？
5. 用标签分组优化排序，为什么能解决刚才的问题？
6. 如果自动识别类别仍使用向量相似度，怎么避免原来的混淆？
7. 用户没有搜到预期结果时，如何分析？
8. 使用的语义模型大致是什么结构，如何训练？

【实习项目】
1. 你说的准确率到底怎么定义？
2. 测试集怎么构造，参考答案从哪里来，谁来评分？
3. 测试是否覆盖文本回答、工具调用等不同任务？
4. 评测只看最终答案，还是也看中间工具调用过程？
5. 为什么选 Plan-and-Execute？
6. 为什么认为 ReAct 会带来更多轮次或更高延迟？
7. 延迟降低主要来自控制模型调用次数，还是其他优化？
8. 如果问题和动作空间都比较固定，为什么不用标准工作流？
9. 是否需要多轮交互，以及状态和上下文管理？

【基础知识】
1. 对大模型训练、推理加速了解多少？
2. MCP 和直接提供 REST API、Function Calling 的区别是什么？
3. 如果把接口说明写成 Skills 文档，让模型照着调用，和 MCP 的区别在哪里？

无手撕。

结果：当天挂

个人感受：这是秋招第一场面，很多东西准备得不够好。比如面试官问实习项目测试集怎么构造的时候，我只答了实际上是怎么做的（实际上使用的方法比较简单），应该补充一下我觉得怎么做会更好等等。问个人项目的时候和他的问题也没有第一时间对齐，应该第一时间搞清楚他到底想问/想考什么。
后续补充了一些大模型训推相关的知识。
