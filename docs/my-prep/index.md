# 项目追问准备册

这是你的个人备考区（不进刷题池）。每一页对应简历上的一个项目/实习，内容是**从真实面经里映射过来的高概率追问链**——面试官当年怎么拷打别人，就会怎么拷打你。

## 使用方法

1. 每条追问先**自己口头答一遍**，再对照「准备要点」补漏
2. 「我的答案要点」留空是给你的——数字、决策原因、踩过的坑只有你知道，填进去才是你的
3. 每条追问都标了真实面经来源，点进去能看到当时候选人的完整遭遇（包括挂在哪）
