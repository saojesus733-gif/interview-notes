## 问题

Agent 的记忆是怎么设计的？短期记忆和长期记忆分别如何实现？

## 核心答案

**短期记忆**：即模型的上下文窗口，保存当前会话的对话历史、工具结果。受窗口长度限制，需要管理：

- 滑动窗口：只保留最近 N 轮；
- 摘要压缩：把久远对话总结成摘要替换原文；
- 关键信息提取：保留系统指令、用户偏好等关键项。

**长期记忆**：存到模型外部，跨会话复用：

- 向量数据库：对话/事实向量化后存储，按语义检索相关记忆注入 Prompt（与 RAG 同机制）；
- 关系型/键值存储：存结构化的用户画像、偏好、事实条目；
- 写入时机：会话结束时总结沉淀，或在对话中按重要度实时写入。

## 深度解析

- 记忆管理三问题：存什么（原始对话 vs 提炼事实）、何时写（实时 vs 会话结束）、如何取（语义检索 vs 按规则）；
- 记忆过多会引入噪音，常见做法是给记忆打重要度/时效分并做淘汰（衰减）；
- 分层记忆思路（如 MemGPT 类方案）：把主上下文当「内存」、外部存储当「磁盘」，由模型自主决定换入换出。
