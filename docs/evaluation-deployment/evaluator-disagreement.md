## 问题

怎么评估一个 Prompt 的质量？两个评估者（或两个 Judge）结论不一致怎么办？

## 核心答案

**Prompt 质量评估方法**：

1. **固定评估集**：覆盖典型输入 + 边界 case + 历史坏例（20~50 条起步），每个候选 Prompt 跑同一集合；
2. **多维度打分**：任务完成度、格式遵循率、幻觉率、拒答恰当性——不只看「答对没」；
3. **多轮稳定性**：同一输入重复采样（尤其非零温度），看输出方差——偶尔对的 Prompt 不可上线；
4. **对照实验**：新旧 Prompt 同集对比，胜率/分项指标变化，而不是单次抽测。

**评估者分歧的处理**：

1. **先量化分歧**：统计一致率；分歧集中在哪些样本/哪些维度——系统性分歧说明 rubric 有歧义，随机性分歧说明判据太主观；
2. **分歧仲裁机制**：
   - 引入第三方 Judge 投票（多数决）；
   - 高分歧样本升级人工标注，人工结论视为 ground truth；
   - 无法定论的样本标记「模糊区」，不计入通过率（但要记录占比）；
3. **修复源头**：把争议样本的判据补进 rubric（写成可观察的行为标准），迭代评估器本身；
4. **监控一致性**：用一致性系数（如 Cohen's kappa 类指标）长期跟踪评估者间一致性，退化即告警。

## 深度解析

- 分歧不是噪音，是**信息**：它暴露了「好输出」定义中的模糊地带，把分歧样本变成 rubric 迭代的燃料，评估体系才能越跑越准；
- Judge 间分歧与 Judge-人工分歧要分开看：前者优化成本，后者决定可信度上限；
- Prompt 版本切换的决策标准要预先约定（如「新版本胜率 ≥ 60% 且无关键维度回退」），避免拍脑袋上线。
