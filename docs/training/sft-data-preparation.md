## 问题

做领域 SFT 时，训练数据怎么准备？"数据越多越好"对吗？

## 核心答案

**核心结论先行：SFT 的效果上限由数据质量与多样性决定，不是数量**——千级高质量精标数据往往胜过十万级噪声数据。

**准备流程四步**：

1. **来源规划**：人工撰写（贵但准）、强模型蒸馏生成（快，需人工抽检）、真实用户会话（最贴近分布，必须脱敏）；
2. **清洗**：去重（精确 + 模糊）、去噪（错误答案/低质量回答剔除）、敏感信息过滤、格式合法性校验；
3. **配比设计**：任务类型覆盖（问答/摘要/抽取/工具调用/拒答），难度分层（简单到复杂），领域数据与通用数据混合（防通用能力遗忘）；
4. **格式对齐**：与训练/推理时的对话模板严格一致——system 字段、多轮结构、工具调用格式错一个 token 都影响效果。

**评估驱动**：建好评估集后，数据配比的每次调整都跑评估对比——数据迭代本身就是实验。

## 深度解析

- 常见失败模式：
  1. **分布错配**：训练数据问法与线上真实用户问法不一致 → 离线很好线上拉胯；
  2. **任务冲突**：不同任务的数据互相拉扯（都想要礼貌 vs 都想要简短），需控制混比；
  3. **灾难性遗忘**：纯领域数据猛训，通用能力退化 → 掺通用数据回炉；
- 加分点：真实用户数据是"最贵的数据资产"——上线后回流会话做 SFT 数据，是产品飞轮的一部分（脱敏与合规是前提）。
